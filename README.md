# TaskFlow

A lightweight, responsive to-do list built with vanilla JavaScript. The interface and styles are generated by `app.js`; `index.html` is a minimal entry point.

## Features

- Add, edit, complete, and delete tasks
- Filter all, active, and completed tasks
- Search tasks by title
- Clear completed tasks
- Light and dark themes
- Saves tasks and theme in browser `localStorage`
- Responsive layout; no frameworks or build step

## Run locally

Open `index.html` in a modern browser. For best results, use a local static server or VS Code Live Server.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Pushes to `main` will run the included Pages workflow.
4. After the workflow succeeds, the site will be available at `https://shreebalaji767.github.io/TaskFlow/`.

Tasks are saved only in the current browser on the current device; they are not synced between devices. Avoid storing sensitive information in tasks.
